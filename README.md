# 🗺️ Interactive University Map and Navigation System

## 📌 Project Overview

The Interactive University Map and Navigation System is a web-based application designed to help students, faculty, staff, and visitors easily navigate the SNIST campus.

The system provides an interactive campus map where users can explore different buildings, rooms, facilities, and locations. It also provides route guidance between selected locations.

## ✨ Features

- 🗺️ Interactive campus map
- 🏫 View different campus buildings and blocks
- 🚪 Room and location information
- 🧭 Route/navigation support
- 📍 Location-based campus exploration
- 🌙 Dark mode
- 🔊 Voice assistance
- 📱 Responsive web interface
- 🖼️ SNIST campus map and logo integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- GitHub
